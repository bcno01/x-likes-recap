# いいねリキャップ

X (旧Twitter) の公式データアーカイブに含まれる `like.js` を読み込んで、指定した期間にいいねしたポストをまとめて表示するツールです。ブラウザだけで動作し、サーバーやアカウントは不要です。

## 使い方

1. Xアプリ or ブラウザで 設定 →「アカウント」→「データのアーカイブをダウンロード」をリクエストする
2. 準備ができるとメール通知が届くので、アーカイブ(zip)をダウンロードする
3. ダウンロードした `.zip` をそのままこのアプリにドラッグ&ドロップ、またはタップしてファイル選択で読み込む(zipの中から `data/like.js` を自動で探して読み込むので、展開する必要はない。もちろん展開済みの `like.js` を直接ドロップしてもよい)。複数ファイルをまとめて選択/ドロップすることもでき、既存の内容に追加される(同じポストが重複していれば自動でまとめられる)。全部消してやり直したいときは「すべてクリア」を押す
5. 「全期間」「過去30日」「過去6ヶ月」「〇〇年(今年の1/1〜12/31)」のボタン、または「📅 期間を指定」から開くカレンダーで期間を選ぶと、該当するポストだけが一覧表示される(初期状態は全期間。「過去30日」「過去6ヶ月」「今年」は実行時点の日付が基準)
6. 「並び順」で新しい順/古い順/ランダムを切り替えられる(いいね数でのソートには対応していません。Xのアーカイブにいいね数の情報が含まれていないため)
7. ポストの枠内をタップすると、そのポストのURLがクリップボードにコピーされる
8. 各ポストの「Xで開く →」から元のポストを新しいタブで開ける
9. 左端のチェックボックスでポストを選択すると、画面下に選択件数と「まとめて表示」ボタンが出る。選択したポストだけの一覧に切り替わり、そこから「テキストをコピー」や共有/ダウンロードができる。この「まとめて表示」画面では、Xの公式埋め込みツイート(アイコン・表示名・いいね数など込みの本物の見た目)で表示される
   - **画面幅が広い(目安1024px以上、PC向け)ときは左右2カラムのレイアウトになり、左の一覧でチェックを入れると右側にリアルタイムで反映される。**「まとめて表示」ボタン操作は不要(常に右側に表示されている)

## 注意事項

- **表示される日付は「いいねした日時」ではなく「そのポストが投稿された日時」です。** Xの公式アーカイブにはいいねした日時そのものが記録されておらず、ポストのID(Snowflake ID)から算出できる投稿日時を代わりに使っています。
- **ブックマークには対応していません。** ブックマークはXの公式データアーカイブに含まれていないため(既知の仕様上の欠落)、このツールでは扱えません。
- 読み込んだデータはブラウザ内のメモリ上で処理されるだけで、どこにも送信されません。ページを閉じる/リロードするとデータは消えるので、再度使うときは `like.js` を読み込み直してください。
- いいねが削除されたポストの本文を含んでいた場合、そのテキストがそのまま表示されることがあります。
- 埋め込み表示(「まとめて表示」、またはPC幅の右側パネル)は `platform.twitter.com` から読み込むため、表示にはネットワーク接続が必要です(ポストを選択したときだけそのツイートIDがXに送信されます)。何も選択しなければ一覧画面は外部通信が発生しない軽量表示のままです。削除済み・非公開になったポストは埋め込みが表示できない場合があります。
- `like.js` には添付画像・動画のURLが含まれていません。一覧ではサムネイルを表示できないため、画像を確認したい場合はチェックボックスで選択して「まとめて表示」(またはPC幅の右側パネル)から埋め込みで確認してください。

## インストール(PWA)

このアプリはPWAとして端末にインストールできます。

- **Safari(iPhone/Mac)**: 共有メニュー →「ホーム画面に追加」/「Dockに追加」
- **Chrome**: アドレスバーのインストールアイコンから追加

## 技術構成

- 素のHTML/CSS/JavaScript(ビルド不要)
- zipファイルの解凍のみ [JSZip](https://stuk.github.io/jszip/) をCDN経由で利用
- 「まとめて表示」の埋め込みポストのみ `platform.twitter.com/widgets.js` をオンデマンド読み込み(初回「まとめて表示」時のみ)
- `like.js`(JSラッパー付きJSON)をパースし、各ポストIDからSnowflake形式で投稿日時を算出
- ファイル処理はすべてブラウザ内で完結(外部送信・サーバー保存なし)
- Service Workerでアプリ本体をキャッシュ(`sw.js`)
- GitHub Actionsで`main`ブランチへのpush時に自動デプロイ(`.github/workflows/pages.yml`)
